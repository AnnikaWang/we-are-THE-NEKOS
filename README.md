## Neko Notes

Neko Notes is a small Manifest V3 browser extension that offers gentle mental health affirmations from Miso the cat. It runs locally and stores one saved thought in the browser.

### Run it locally

1. Open `chrome://extensions` (or the equivalent extensions page in your browser).
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this repository folder.
4. Pin **Neko Notes**, then open it from the browser toolbar.

The **Another one** button rotates through affirmations. **Save this thought** persists the current message with extension storage.
